# Community courses

Each course belongs in `courses/<github-login>-<course-slug>/`. Share from **Teach Me → Course hub → Share a course** to create the folder and open a pull request, or follow the manual steps in the [repository README](../README.md#share-a-course).

Visit [teach-me.software](https://teach-me.software/) for Teach Me. The first published course is [Robotics: Build a Voice-Controlled Robotic Hand](andrewnovykov-robotics-build-a-voice-controlled-robotic-hand/).
