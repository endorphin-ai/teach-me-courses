# Per-lesson plans (each: hook, key idea first, then concept -> analogy -> example -> checkpoint; mistake, challenge, homework)
- 01-meet-the-circuit: circuits, GPIO, Arduino IDE on Mac, blink. Hook: a board that switches the world. Order the hand and parts.
- 02-first-code: variables, if, functions, Serial in and out. Hook: make the board talk back.
- 03-servo-motion: PWM, servo power, ESP32Servo. Hook: a stalled servo resets the board. Widget: pulse width to angle.
- 04-the-hand: tendon fingers, calibration arrays, gesture functions.
- 05-typed-commands: read a line, command table, smooth motion.
- 06-microphone: sampling, I2S INMP441, loudness and threshold. Widget: threshold.
- 07-keyword-spotting: Edge Impulse; recording samples; confidence. Widget: confidence gate.
- 08-voice-hand: pipeline, cooldown, tuning, final demo.
